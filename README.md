# QuickNotes

QuickNotes is a simple, responsive note-taking web app that lets you quickly create, organise, search and delete notes using Personal, Work and Study categories. Notes are stored in the browser with localStorage, so they remain available after a page refresh.

## Features

- Add notes with Personal, Work or Study categories
- Validate empty notes and notes longer than 200 characters
- Display notes as readable cards with category and date information
- Delete individual notes
- Search notes by one or more words without regard to letter case
- Persist notes with browser localStorage
- Show an accurate note count
- Responsive layout for small screens

## How to run locally

1. Clone or download this repository.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a modern web browser.
4. No build tools or dependencies are required.
